# HR-Employee-Attrition-Analysis-Dashboard-Power-BI-
Interactive Power BI dashboard for analyzing HR employee attrition, workforce demographics, job satisfaction, and key HR metrics to identify attrition trends and support data-driven workforce decisions.

📌 Project Overview

This project analyzes employee attrition data using Power BI to identify workforce trends, understand the factors influencing employee turnover, and provide actionable HR insights. The dashboard helps HR teams monitor employee demographics, attrition rates, job satisfaction, and departmental performance through interactive visualizations.

🎯 Objectives
Analyze employee attrition across departments.
Identify factors contributing to employee turnover.
Monitor workforce demographics and job roles.
Evaluate employee satisfaction and work-life balance.
Support HR decision-making with actionable insights.
